# Как делить задачи между GPT-5.5 и GPT-5.3-Codex-Spark

## GPT-5.5

Использовать для:

1. Архитектуры проекта.
2. Создания начального скелета.
3. Моделей данных.
4. Сервисов аналитики.
5. Логики coach report.
6. Сложных багов.
7. Рефакторинга.
8. Финальной ревизии качества.
9. Решений по demo parsing.
10. Решений по Steam auth.

Примеры задач:

```text
Изучи ТЗ в md-файлах и создай архитектурно чистый MVP проекта CS2 Personal Coach.
Сделай FastAPI приложение с импортом CSV/JSON, БД, аналитикой, coach report и базовым dashboard.
Не делай Steam auth и demo viewer в первой итерации.
После реализации запусти тесты и опиши, что работает.
```

```text
Проведи архитектурный review проекта. Найди дублирование, слабые места, неправильное разделение слоёв. Исправь без поломки текущего функционала.
```

## GPT-5.3-Codex-Spark

Использовать для:

1. HTML templates.
2. CSS.
3. Chart.js графиков.
4. README.
5. Тестов.
6. Sample CSV/JSON.
7. Маленьких endpoint.
8. CSV export.
9. Markdown report formatting.
10. Небольших bugfix.

Примеры задач:

```text
Добавь страницу /matches с таблицей матчей, фильтрами по карте и периоду. Используй текущие модели и сервисы, не меняй архитектуру.
```

```text
Добавь Chart.js графики на dashboard: KD, ADR, KAST, rating по последним 30 матчам.
```

```text
Напиши pytest-тесты для importer.py, analytics.py и coach_rules.py.
```

## Главное правило

Не давать двум агентам одновременно менять одни и те же файлы без синхронизации.

Сначала GPT-5.5 создаёт скелет. Потом Spark делает мелкие задачи. Потом GPT-5.5 проводит ревизию.
