Как включить автоматическую подгрузку матчей Steam

OpenID + Game Authentication Code
1. Подключить Steam Кнопка выше отправит на официальный Steam OpenID. После возврата приложение получит только SteamID, без логина и пароля.
2. Получить Game Authentication Code Открой Steam Support для CS2, найди раздел доступа к истории матчей / Game Authentication Code и создай код для Counter-Strike 2. Документация Valve описывает этот код как способ дать сервису доступ к истории матчей.
Steam Support CS2 Valve Match History docs
3. Вставить код здесь После сохранения мы включим sync и поставим задачу в очередь. Следующий слой воркера будет ходить в Steam match history, получать share codes и докачивать демки.
