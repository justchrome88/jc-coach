# Roadmap CS2 Personal Coach

## День 1 / Ночной прогон

Цель: рабочий MVP через CSV/JSON.

- FastAPI app.
- DB.
- Import CSV/JSON.
- Dashboard.
- Matches table.
- Analytics.
- Coach rules.
- Markdown report.
- README.
- Tests.

## День 2

Цель: сделать продукт приятным для личного использования.

- Улучшить dashboard.
- Добавить графики.
- Добавить фильтры.
- Добавить импорт новых файлов без дублей.
- Добавить настройки player profile.
- Улучшить coach prompt.
- Начать ручной сбор своих матчей.

- Добавить список тренировочных задач.
- Подключить OpenAI API, если нужно.
- Протестировать на своих последних 30–50 матчах.

Цель: demo parsing.

Цель: Steam profile.

- Привязать данные к пользователю.
- Закрыть сайт авторизацией.

Цель: первые тестеры.

- Дать 2–3 друзьям загрузить данные.
- Собрать обратную связь.
