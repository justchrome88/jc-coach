# Steam, demo import и ограничения

## Steam login

Для веб-сайта использовать вход через Steam только для идентификации пользователя и получения SteamID.

Нельзя просить пользователя вводить Steam login/password на нашем сайте.

## Что Steam login даёт

- подтверждение личности;
- SteamID;
- публичные данные профиля, если доступны через API.

## Что Steam login НЕ гарантирует

Steam login сам по себе не гарантирует простой доступ ко всей истории матчей CS2 и демкам.

Автоматический импорт матчей может потребовать:
- share codes;
- auth code;
- обращения к Steam/CS2 Game Coordinator;
- использования библиотек Steam client/GC;
- аккуратного исследования актуального состояния API.

Эту задачу делать отдельным этапом, не смешивать с MVP.

## Рекомендуемый порядок

### Этап 1

CSV/JSON import.

### Этап 2

Manual `.dem` upload.

### Этап 3

Steam profile login.

### Этап 4

Share code import/manual.

### Этап 5

Semi-auto demo downloader.

## Demo parsing

Изучить актуальные библиотеки:

- demoparser2;
- awpy;
- другие активные CS2 demo parser проекты.

Для MVP demo parser должен быть optional. Если парсер не ставится или ломается, приложение всё равно должно работать через CSV/JSON.

## Важная инженерная позиция

Не строить продукт вокруг непроверенной гипотезы “Steam легко отдаст все мои матчи”.

Сначала сделать работающий импорт данных и тренерский отчёт. Потом постепенно автоматизировать источники.
