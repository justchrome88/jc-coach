# Release Checklist

Source preserved at `_legacy_archive/r02a2-2026-07-11/docs/RELEASE_CHECKLIST.md`.

- [ ] Required work packages and acceptance evidence are complete.
- [ ] Full local quality gate and focused regressions pass.
- [ ] Production DB and service mutation evidence matches task authorization.
- [ ] Known metric, playlist, and scope limitations are visible.
- [ ] Current status, handoff, registry, roadmap, and acceptance matrix agree.
- [ ] No secrets, DBs, demos, caches, or temporary files are staged.
- [ ] Push/deployment has separate explicit authorization.
