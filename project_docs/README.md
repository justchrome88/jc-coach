# JC Coach Human Documentation

This is the canonical root for current human-facing Product documentation.

- `product/`: behavior, coach domains, recommendations, and limitations.
- `architecture/`: system, API, import, AI, mission, and decision contracts.
- `operations/`: deployment, backup/restore, migrations, security, testing,
  and Steam import operations.
- `metrics/`: metric governance, lineage, coach requirements, contracts, and
  the generated catalog.
- `acceptance/`: reusable accepted replay and acceptance procedures.

Current status, routing, checklists, and agent policy live in
`project_control/`. Runtime machine contracts live in `app/contracts/`.
Historical reports and superseded material live only in `_legacy_archive/`.

Sources migrated byte-identically are recorded in
`_legacy_archive/r02a2-2026-07-11/MIGRATION_MANIFEST.json`.
