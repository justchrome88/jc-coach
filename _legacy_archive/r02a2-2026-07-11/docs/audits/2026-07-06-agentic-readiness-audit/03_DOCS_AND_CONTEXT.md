# Docs And Context

## Findings

- `AGENTS.md` is the active root contract and `AGENT.md` is a superseded pointer.
- `docs/CURRENT_STATUS.md`, `docs/HANDOFF.md` and `docs/project_management/WP_REGISTRY.md` are current as of 2026-07-06.
- `docs/project_management/DOCS_INDEX.md` and `DOCS_MAP.md` provide the practical project index even though no file named `PROJECT_INDEX` exists.
- Warm/Cold context classification is unusually strong for an agent-operated repo.
- Old audit reports, old task prompts and `instructions/*` are numerous, but are classified as evidence/history rather than current truth.

## Risks

- The volume of old docs can still pollute agent context if the Hot/Warm/Cold protocol is ignored.
- `docs/KNOWN_LIMITATIONS.md` is useful but not a full risk register: it lacks owner, status, priority and target WP fields.
- Governance is not fully machine-enforced.
