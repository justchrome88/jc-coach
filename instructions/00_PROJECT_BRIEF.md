# CS2 Personal Coach — краткое ТЗ проекта

## Цель

Создать личный веб-сервис для анализа матчей Counter-Strike 2 и выдачи практических тренерских рекомендаций.

Главная идея: это не клон Scope.gg и не просто сайт со статистикой. Это персональный AI-тренер, который берёт данные матчей/демок, считает метрики, находит повторяющиеся ошибки и выдаёт конкретный план улучшения на 7 дней.

## Режим разработки

Сначала делаем MVP для одного пользователя — владельца проекта. Без коммерции, платежей и публичной регистрации. Архитектура должна быть такой, чтобы позже можно было добавить авторизацию других пользователей, Steam login, очереди обработки демо, тарифы и публичный доступ.

## Главный критерий успеха MVP

После загрузки матчей/демок система должна ответить:

1. В чём мои 3 главные проблемы.
2. Почему они мешают росту.
3. На каких картах/сторонах/типах раундов это проявляется.
4. Что конкретно тренировать следующие 7 дней.
5. По каким метрикам понять, что стало лучше.

## Что не делать в первой версии

Не делать сразу:
- публичный SaaS;
- платежи;
- сложную регистрацию;
- мультипользовательские роли;
- идеальный 2D-demo viewer;
- социальные функции;
- маркетинговый лендинг;
- мобильное приложение;
- Steam-интеграцию любой ценой, если она тормозит MVP.

## Базовый технический стек

Рекомендуемый стек для MVP:

- Python 3.11+ или 3.12
- FastAPI
- SQLite для первого локального MVP или PostgreSQL для VPS
- SQLAlchemy 2.x
- Alembic, если используется PostgreSQL
- Jinja2 + HTMX или простой server-rendered HTML
- Chart.js для графиков
- demoparser2 или awpy для разбора .dem
- OpenAI API опционально для AI-отчётов
- Docker Compose для запуска на Ubuntu VPS

## Философия продукта

Статистика сама по себе не ценность. Ценность — вывод и следующий шаг.

Плохой результат:
> K/D 1.06, ADR 76, KAST 74%.

Хороший результат:
> У тебя нормальный aim и приемлемый KAST, но utility impact слабый. На Mirage и Ancient ты часто проигрываешь T-side, потому что мало создаёшь пространства и плохо разыгрываешь early-round. Следующие 7 дней фокус: 3 стандартных smoke/molotov-пака, entry/trade дисциплина, death review первых 30 секунд раунда.
