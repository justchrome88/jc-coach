# Готовые команды/промпты для Codex

## Ночная команда для GPT-5.5

```text
Изучи все .md файлы в корне репозитория. Особенно 01_OVERNIGHT_MVP_TASK.md и 03_CODEX_AGENT_RULES.md.

Твоя задача: реализовать MVP v0.1 проекта CS2 Personal Coach.

Сделай:
1. FastAPI приложение.
2. SQLite БД через SQLAlchemy.
3. Импорт CSV/JSON матчей.
4. Dashboard.
5. Страницу списка матчей.
6. Аналитику последних матчей.
7. Сравнение последних 15 против предыдущих 15.
8. Rule-based coach report.
9. Markdown/HTML страницу отчёта.
10. Sample CSV/JSON.
11. README.
12. Минимальные тесты.

Не делай:
- Steam auth;
- платежи;
- публичную регистрацию;
- demo viewer;
- сложный React frontend.

Работай автономно. После реализации запусти тесты/smoke-check. В конце напиши, что сделано, как запустить, какие файлы созданы, что проверить утром.
```

## Утренняя команда для проверки

```text
Проверь проект после ночной реализации.

1. Запусти тесты.
2. Запусти приложение.
3. Проверь /health.
4. Загрузи sample CSV.
5. Проверь, что матчи появились.
6. Проверь dashboard.
7. Сгенерируй coach report.
8. Исправь найденные ошибки.
9. Обнови README фактическими командами запуска.
```

## Команда для Spark: UI

```text
Не меняя архитектуру backend, улучши UI.

Сделай dashboard визуально приятнее:
- dark theme;
- карточки метрик;
- графики Chart.js;
- таблица последних матчей;
- блок Coach Focus;
- аккуратная страница отчёта.

Не добавляй React. Используй текущие templates/static.
```

## Команда для Spark: тесты

```text
Добавь тесты для MVP.

Покрыть:
1. CSV импорт с полными и неполными колонками.
2. JSON импорт.
3. Дедупликацию матчей.
4. Summary analytics.
5. Period comparison.
6. Weakness detection.
7. Markdown report generation.

После этого запусти pytest и исправь ошибки.
```

## Команда для GPT-5.5: demo parser research

```text
Изучи текущий проект и подготовь модуль demo_parser.py как optional experimental.

Задача:
- исследовать, можно ли подключить demoparser2 или awpy;
- добавить загрузку .dem;
- если библиотека ставится, извлечь базовые события: kills, deaths, rounds, damage, utility;
- если библиотека не ставится, сделать заглушку с понятным TODO и не ломать приложение.

Не превращай это в главный scope. CSV/JSON MVP должен оставаться рабочим.
```
