# Краткая постановка задачи для соседнего чата

Мне нужен набор ТЗ и инструкций для Codex, чтобы быстро начать проект CS2 Personal Coach.

Суть проекта:

Я хочу сделать личный сайт для анализа своих матчей CS2. Не просто статистику, а персонального AI-тренера: загрузка матчей/демок, красивые графики, анализ слабых мест, сравнение периодов, выводы по картам и тренировочный план на 7 дней.

На первом этапе это личный проект для меня. В будущем, если окажется полезным, можно расширить до друзей и коммерческого продукта.

Нужно подготовить:

1. ТЗ на полноценный личный продукт:
   - красивый сайт;
   - Steam login;
   - импорт матчей;
   - загрузка `.dem`;
   - demo parsing;
   - дашборды;
   - AI coach;
   - архитектура под расширение.

2. Отдельное ТЗ на быстрый ночной MVP:
   - без Steam auth;
   - без продаж;
   - без мультипользователей;
   - импорт CSV/JSON;
   - база матчей;
   - dashboard;
   - сравнение последних 15 матчей с предыдущими 15;
   - rule-based coach report;
   - AI report optional;
   - README и тесты.

3. Инструкции для Codex:
   - как работать в репозитории;
   - что делать и чего не делать;
   - как проверять результат;
   - какие файлы создавать;
   - какие acceptance criteria.

4. Отдельный список данных и метрик, которые нужно вытаскивать из матчей/демок:
   - сухая статистика;
   - round-level данные;
   - event-level данные;
   - utility;
   - deaths;
   - entry;
   - trade;
   - карты;
   - стороны;
   - heatmaps;
   - будущий 2D viewer.

Главный фокус MVP: к утру получить не красивую пустую оболочку, а рабочий инструмент, который принимает данные матчей и выдаёт полезный тренерский отчёт.
